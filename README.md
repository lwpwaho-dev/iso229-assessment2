# ISO229 Assessment 2 - HTML5 Website
**Course:** ISO229 Web Design  
**Assessment:** Assessment 2 - HTML5 Website (10%)  
**Topic:** Vanimo Surf Lodge & Annual Surf Competition Website  

## 1. Project Purpose & Target Audience
- **Purpose:** To promote Vanimo Surf Lodge's eco-accommodation, surf tours, and the Annual Vanimo Surf Pro competition in Sandaun Province, Papua New Guinea.
- **Target Audience:** Local PNG surfers, PNG-based expatriates seeking weekend getaways, and international surf tourists visiting during the swell season.

## 2. Website Structure
The website consists of 3 connected semantic HTML5 pages:
1. `index.html` - Home page introducing Lido Village beachfront accommodation, Sarp Point reef breaks, and the annual competition.
2. `services.html` - Breakdown of surf stay packages, guided charters, and the Annual Vanimo Surf Pro schedule table.
3. `contact.html` - Booking and contest entry form with input validation (`required`, `type="email"`, `type="tel"`, `select`, `radio`, `checkbox`, `textarea`).

## 3. HTML5 Semantic Elements Used
- `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<address>`, `<footer>`
