# ISO229 Assessment 4 - Individual Integrated Web Design Project
**Course:** ISO229 Web Design  
**Assessment:** Assessment 4 - Individual Integrated Web Design Project (10%)  
**Topic:** Vanimo Surf Lodge & Annual Surf Competition Website  

## 1. Project Purpose & Target Audience
- **Purpose:** To finalize the multi-page Vanimo Surf Lodge web application into an integrated solution combining semantic HTML5, responsive CSS3 (Flexbox/Grid), accessibility standards, and vanilla JavaScript interactivity.
- **Target Audience:** Local PNG surfers, PNG-based expatriates, and international surf tourists.

## 2. Integrated Features & Technologies
- **Semantic HTML5:** Multi-page layout (`index.html`, `services.html`, `contact.html`) with semantic document outlines.
- **Responsive CSS3 Layouts:** CSS variables, Flexbox header/nav alignment, CSS Grid card arrays (`.card-grid`), and viewport media queries.
- **JavaScript Feature 1 (Mobile Navigation Toggle):** Accessible hamburger menu toggling navigation list visibility on viewports under 768px with dynamic `aria-expanded` updates.
- **JavaScript Feature 2A (Interactive Trip Cost Calculator):** Dynamic cost estimator on `services.html` calculating package totals, night counts, guest totals, and add-ons in Papua New Guinea Kina (PGK).
- **JavaScript Feature 2B (Form Validation Engine):** Client-side validation on `contact.html` intercepting submission errors, highlighting invalid inputs (`.input-error`), and rendering live feedback.

## 3. Testing Evidence
- **Functional & Cross-Browser:** Verified link routing, calculator math, and form error handling across Google Chrome and Mozilla Firefox.
- **Responsive & Viewport Testing:** Verified layouts across Mobile (<768px), Tablet (768px–1023px), and Desktop (1024px+) viewports.
- **Validation & Accessibility:** Confirmed HTML5 semantic validity via W3C Markup Validator and verified visual `:focus` outlines and ARIA attributes.
